CoreLoopDebugUI.cs에서 F1 키를 눌러 디버그 UI를 켜고 끌 때 한 번만 눌러도 즉시 토글되도록 입력 처리 위치를 수정해 줘.

1. 수정 사항 (Assets/Scripts/UI/CoreLoopDebugUI.cs)
- 현재 OnGUI() 내부에서 Input.GetKeyDown(KeyCode.F1)이나 Event.current로 F1 토글을 처리하고 있다면 해당 입력 체크 코드를 제거해 줘. (OnGUI는 한 프레임에 Layout/Repaint 등으로 여러 번 호출되어 토글이 중복 실행되는 버그가 발생함)
- 대신 한 프레임에 단 한 번만 호출되는 Update() 메서드를 작성하고, 그 안에서 `if (Input.GetKeyDown(KeyCode.F1)) { isVisible = !isVisible; }` 형태로 토글 상태를 변경하도록 수정해 줘.
- OnGUI()의 최상단에서는 `if (!isVisible) return;`만 검사하도록 깔끔하게 유지해 줘.
